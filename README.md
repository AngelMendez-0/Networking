# Computer Networks

## Description
This repository contains projects from CSCD 330 (Computer Networks). The goal of these projects is to develop an understanding of networking concepts such as DNS resolution, web APIs, data retrieval, and network data visualization using Python and Unix networking tools.

## File Descriptions

### Lab 2 – Web API Temperature Forecast
Programs demonstrating how to retrieve and process network data using multiple APIs. This lab focuses on converting a domain name into an IP address, retrieving company location data, using web APIs to gather weather information, and plotting hourly temperature forecasts using Python.
