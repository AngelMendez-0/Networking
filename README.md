# Computer Networks

## Description
This repository contains projects from CSCD 330 (Computer Networks). These projects cover networking fundamentals including APIs, socket programming, packet construction, and network routing using Python and Unix tools.

## File Descriptions

### Lab 2 – Web API Temperature Forecast
Python program that retrieves location and weather data from multiple APIs and plots hourly temperature forecasts for a given domain.

### Lab 4 – HTTP Client with TCP Sockets
Python TCP client that retrieves webpages using HTTP GET requests and outputs the page contents to either the console or a file.

### Lab 6 – Packet Construction with Scapy
Python program using Scapy to manually perform a TCP three-way handshake and send an HTTP GET request while analyzing network traffic.

### Lab 7 – TCP Traceroute Tool
Python program that implements a TCP traceroute tool to identify network hops and Autonomous Systems involved in reaching a destination server.
